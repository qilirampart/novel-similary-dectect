# 短剧字幕 Reranker 试点评估

## 评估范围

本轮使用 Gitee `POST /v1/sentence-similarity` 接口和 `bce-reranker-base_v1` 模型，对混合召回产生的有限候选做独立重排。Reranker 只接收查询台词与候选证据窗口，不参与 Qdrant 召回，也没有改变当前默认混合排序。

## 接口可用性

三类人工构造文本的返回结果正常：精确复用得分 `0.664214`，轻度改写得分 `0.590307`，无关文本得分 `0.248170`。这说明接口能够区分大致相关程度，但分数仍需在真实标注样本上校准，不能直接当作侵权概率。

## 真实短剧候选测试

使用中文台词“大哥这是横店吗你们是不是在拍戏”及当前混合召回的 10 个候选进行测试，Reranker 单次耗时约 `0.24` 秒。Reranker Top1 仍为词级强命中候选 `41000010048` 第 1 集，得分 `0.529415`；其余候选主要来自语义补召回，分数约为 `0.406626` 至 `0.475788`。

本轮结果说明 Reranker 在该样本上没有破坏强词级命中，并能对语义候选进一步排序。但这只是单条样本，不能证明整体召回准确率或误报率改善。

## 代码与边界

已新增 `service/drama_subtitle_reranker.py`，提供模型、token、接口、超时和候选重排函数；对返回数量不一致和非法分数会明确报错。已增加离线模拟测试，当前相关测试 `5 passed`。

Reranker 暂不接入默认单条或批量链路，避免外部 API 延迟和模型分数在未校准前影响现有结果。后续应使用人工确认的正确、待定、错误候选集，对词级、混合排序和 Reranker 排序分别统计 Top1、TopK、误报和耗时，再决定是否灰度启用。
