## 口径与当前基线

本轮中台表共 50,014 个唯一 Book ID。旧采集数据覆盖 24,239 个，本轮新增 25,775 个。新旧采集结果合并后，接口可查 47,564 部，全剧有真实字幕 14,512 部，前 5 集有真实字幕 14,464 部。

当前正式匹配库为 `data/drama_subtitle_similarity_v1.sqlite3`，现有 7,108 个 Book ID、3,195,806 条字幕行、309,198 个匹配窗口。当前库与合并覆盖表中的前 5 集有字幕剧交集为 7,094 部，说明新增字幕目前还没有正式进入匹配 SQLite。原始采集文件已保存，但不等于已经可以被前台召回。

导入范围默认使用采集到的真实字幕前 10 集。接口无返回、只有空字幕占位或前 10 集没有真实字幕的 Book ID 不写入可匹配语料，但继续保留在覆盖统计表中。

## 执行边界

本轮只增加字幕数据，不修改小说库，不修改 Book ID 参与召回或最终判定的逻辑，不改变已有窗口参数、语言路由和命中阈值。基准表中的 ID 仅作为覆盖核验字段，不能参与检索排序。

任何阶段出现旧 Book ID 数量下降、旧样本召回结果变化、主键冲突无法解释、FTS 数量不一致或 Qdrant/SQLite 不一致，立即停止后续步骤，保留日志并使用 P0 备份回滚，不直接覆盖原库。

## 回滚方案

导入前保存 `drama_subtitle_similarity_v1.sqlite3` 完整副本。SQLite 恢复前停止 API 写入任务，确认没有进行中的字幕导入或向量同步，再替换运行库并执行完整健康检查。Qdrant 使用独立的本地 collection 或记录导入前点数，不能删除现有 collection 作为回滚手段。
