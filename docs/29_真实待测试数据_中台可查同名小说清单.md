# 29_真实待测试数据_中台可查同名小说清单

更新时间：2026-05-03

## 1. 这份清单是什么

这是一批从公司现有 `漫剧线索自查表(1).xlsx` 中筛出来的真实待测试数据。

筛选目标不是“随便找一些有原著的短剧”，而是同时满足下面两个条件：

1. 在漫剧线索表中，`原著小说是否在中台能查找到 = 是`
2. 该原著小说名称和我们当前小说库中的书名做严格标准化后，能够同名命中

这意味着这批数据很适合拿来做下一阶段真实测试：

- 一边去拉对应短剧字幕
- 一边直接在我们现有小说库里找到对应小说
- 后续可以用于 `reuse` 和 `rewrite` 两种模式的真实链路验证

## 4. Excel 字段说明

`real_test_titles_all69_v1.xlsx` 中包含以下字段：

- `测试优先级`
- `原著小说名`
- `短剧名`
- `来源sheet`
- `小说库数据集`
- `小说book_ext_id`
- `库内书名`
- `中台可查`
- `入选原因`
- `计划用途`
- `当前状态`
- `备注`

其中：

- `小说book_ext_id` 可直接作为后续定位小说正文、抽取章节、做对比任务的主键之一
- `当前状态` 当前默认写为 `待下载字幕`
- `备注` 预留给后续人工记录，例如：
  - 字幕已下载
  - 字幕缺失
  - 短剧名与原著名改编差异较大
  - 已完成首轮 reuse 测试
  - 已完成 rewrite 测试

## 5. 推荐使用方式

建议后续按下面顺序推进：

1. 从这 `69` 条里优先挑标题关系更直接、字幕更容易拿到的样本
2. 下载对应短剧前几集字幕
3. 按 `book_ext_id` 在小说库中定位对应小说
4. 先跑 `reuse` 模式，验证直接复用检测链路
5. 再跑 `rewrite` 模式，观察语义召回和最终证据桥接效果

## 6. 当前阶段判断

这批 `69` 条数据的价值很高，因为它们不是手工编的 demo，也不是纯内部构造样本，而是已经和业务侧现有线索表对上了。

因此它们适合作为下一阶段的“真实待测试数据池”长期保留，而不是一次性临时样本。
