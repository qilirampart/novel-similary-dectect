# 云端封面巡检开发进度板

## 范围与原则

本任务只建设云端封面巡检，不修改字幕、ASR、小说检索和现有匹配队列语义。封面业务共用登录与页面框架，但使用独立数据库、独立证据目录和只领取封面任务的独立 worker。`unknown`、请求失败和无法访问不能记为安全或整改完成；历史图片与检测结论不可覆盖。

状态采用：`待办`、`进行中`、`已完成`、`阻塞`。同一时间只保留一个主要任务为进行中。

S4 第五子阶段已完成：staging 只读预检会重新验证清单摘要、工作空间、运行时根目录、路径边界、符号链接、保留期、文件大小和正式图片内容哈希；变化项只会标记跳过。当前仍不更新审计状态、不删除文件。下一步实现持久资产的实时数据库保护复核。

S4 第六子阶段已完成：持久资产预检复用现有生命周期判定器，按资产 ID 重新核验最新版本、敏感检测、案件证据、保留期、原因和大小。计划后保护状态发生变化的资产会自动跳过。两类预检均为只读；下一步设计显式审批和短时执行令牌，删除前还需逐项再次校验。

S4 第七子阶段已完成：schema v10 支持 `planned -> approved` 显式审批，审批前必须再次核对清单 SHA-256 并通过实时预检。高熵执行令牌默认 15 分钟有效，只返回一次，数据库只保存哈希且普通查询不暴露。当前没有令牌消费和删除入口；下一步实现一次性领取、逐项复检和结果审计。
