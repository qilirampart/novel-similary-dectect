## 六、后续优化顺序

第一步应补齐语言识别。至少需要将葡萄牙语与英语区分，不能把所有拉丁字母文本直接归为英文。对于识别不确定的拉丁语种，可先标为 `latin_unknown`，再翻译为英文进行检索。

第二步应让翻译目标由“固定两个语言”改为“字幕库中实际存在的其余语言”，或先根据语义粗召回候选的字幕语言决定翻译目标。日语输入对应韩文原版时必须能够执行日语转韩文。

第三步应修正长 CJK 字幕的词法查询采样。当前中文、日文、韩文只使用开头前 80 个三元词，英文四词组则会在全文均匀采样。应将 CJK 改为全文均匀采样或分段检索，否则命中内容位于后半段时容易漏召回。

第四步应保留翻译回退的 Top10 候选、分数和证据。当前结果只记录每次翻译的候选数量和最终结果，无法直接复核翻译后二次召回到了哪些剧。

第五步再调整判定策略。建议新增“翻译后原版候选排名靠前、语义分数较高、同一 Book ID 多窗口稳定出现”的翻译辅助待复核分支，降低语义待复核门槛，但继续保持自动确认命中的词法证据要求。这样可以提高召回覆盖率，同时避免把语义相似但并非同剧的内容误报为确认命中。

中文组应先回查基准表中原版 ID 的来源和关联过程。基准映射未确认前，不建议用这 10 条作为召回参数调优样本。

## 七、优化实施结果

以上非中文问题已于 2026-08-27 完成本地实现，自动确认命中的强词法门槛保持不变，新增能力只扩大跨语言候选召回并将可信结果提升为待复核。

- 已增加葡萄牙语识别，葡萄牙语不再被误标为英文；自动识别后优先翻译为英文检索。
- 日语、中文、韩文、英文的翻译回退由固定两个目标语言扩展为其余三个库内语言；日语目标顺序调整为中文、韩文、英文。
- CJK 长文本词法检索由“只取开头 80 个三元词”改为“保留密集开头并从全文均匀补充采样”，降低命中片段位于后半段时的漏召回。
- 翻译后二次语义检索使用更细的 500 字窗口和 120 字重叠，提高局部剧情命中的稳定性；原语言快速路径不受影响。
- 翻译回退会记录每个目标语言的候选剧、Book ID、集数、语义分数、召回来源、覆盖指标和证据文本，不再只记录候选数量。
- 新增保守的翻译语义待复核规则：综合语义分数、与其他剧分差、同一 Book ID 在多个集数或窗口的重复出现情况选择候选，但不会仅凭语义分数自动确认命中。
