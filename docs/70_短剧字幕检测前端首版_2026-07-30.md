# 短剧字幕检测前端首版

新增页面路由：

```text
/drama-subtitles
```

页面通过侧边栏和顶部导航中的“短剧字幕比对”入口访问，与小说单条比对和小说批量任务分开。

首版包含三个区域：

- 单条字幕检测：输入台词后调用短剧专用接口，显示识别语言、候选剧集、命中集数、时间范围和原始字幕证据。
- 批量任务创建：支持拖入或选择 Excel、CSV、TSV、TXT 文件，创建独立短剧字幕任务。
- 短剧任务与结果：自动刷新排队或运行中的任务，展示每条输入的语言路由、命中剧集、命中集数、耗时和时间证据。

页面没有把词法 BM25 原始值展示为风险分。当前用户重点看到的是候选排名、命中窗口数量与可直接定位的字幕时间范围；风险判断与复核工作将在短剧专用复核页落地。

已完成 `npm run build`，TypeScript 与 Vite 生产构建通过。浏览器自动化运行环境初始化超时，因此本轮未能完成本机可视化截图验证；下次本地前后端服务启动后应优先人工验证上传、轮询和证据展示。
