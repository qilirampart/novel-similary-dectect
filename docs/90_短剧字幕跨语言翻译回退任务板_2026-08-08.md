# 短剧字幕跨语言翻译回退任务板

## 目标

当短剧字幕以原语言检索后未形成可靠内容命中时，服务端将原字幕翻译为语料量充足的目标语言再次检索。低置信的 `potential_match` 也会进入回退，避免不相关的弱候选阻断跨语言召回。原文、译文、翻译方向和命中证据均保留，以支持后续人工复核。

翻译只扩展召回，不能替代原文直接文本证据。翻译后出现候选时统一返回 `translation_assisted_match` 与 `review_required`，不会自动写成确认命中；只有原语言直接证据才可返回 `confirmed_match`。

## 语言策略

| 原语言 | 回退顺序 | 依据 |
| --- | --- | --- |
| 中文 | 英文、韩文 | 英文语料约 21.9 万窗口，韩文约 1,353 窗口 |
| 英文 | 中文、韩文 | 中文语料约 8.9 万窗口 |
| 日文、韩文 | 中文、英文 | 中文和英文语料量显著更大 |

日文当前仅有 22 个字幕窗口，不作为默认翻译目标，避免无意义的外部 API 消耗。原语言已形成可靠内容命中时不触发翻译；`no_match` 与低置信 `potential_match` 可进入回退。

## 已验证结果

- DeepL Free 当前账户额度为 1,000,000 字符。
- 中文到英文、英文到中文请求均成功。
- 同一用户同一原文的第二次翻译命中缓存，不再请求 DeepL。
- 自动化回归共 47 项通过，前端 TypeScript 与生产构建通过。
- 云端视频接口已用真实中文库窗口的英文译文验证：回退至中文后返回 `translation_assisted_match`，命中预期剧集；首次翻译请求约 9.1 秒，缓存命中后约 1.9 秒。
- 云端视频接口已验证随机英文文本：完成两个目标语言回退后仍返回 `no_match`，不会将翻译候选写成确认命中。

## 云端发布与回滚

当前云端 release：`20260808-deepl-video-translation-fix-1`。

发布文件包括 API 配置、请求模型、任务执行器、业务数据库迁移、翻译服务和前端构建产物。DeepL 密钥仅写入 `novel-similarity-api.service` 的 systemd 环境变量；本地 `.env.local.ps1` 已被 Git 忽略。发布命令必须同时保留既有 Qdrant、字幕数据库和 worker 并发环境变量。

若健康检查失败，发布脚本会恢复 `current` 软链接并重启上一 release。发布前不修改共享字幕 SQLite 或 Qdrant collection。
