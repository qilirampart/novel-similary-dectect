# 短剧字幕批量任务后端实施记录

## 完成范围

短剧字幕检测已从单条词法接口扩展为独立批量任务链路。任务不写入小说的 `compare_tasks`、`compare_task_items` 或小说复核表，而是使用：

- `drama_subtitle_tasks`
- `drama_subtitle_task_items`

任务项字段围绕短剧字幕证据设计，包括输入短剧名、集数、作者、平台、输入语言、命中 `book_id`、命中剧名、命中集数、命中语言、词法得分、证据窗口及时间范围。

## 接口

- `POST /api/v1/drama-subtitles/tasks`：上传 `.txt`、`.csv`、`.tsv` 或 `.xlsx` 批量输入，创建短剧字幕任务。
- `GET /api/v1/drama-subtitles/tasks`：读取当前登录用户的短剧任务列表。
- `GET /api/v1/drama-subtitles/tasks/{task_id}`：读取任务状态及各输入项的候选、语言和证据时间。

Excel 解析复用现有输入兼容逻辑，可识别 `query_text`、字幕、短剧名、集数、作者、平台等常见字段；解析后的任务项仅进入短剧专用表。

## 执行机制

自动 worker 在小说任务队列没有待执行任务时，会领取短剧字幕队列。短剧任务当前执行的步骤为：

1. 解析上传文件。
2. 自动识别输入语言。
3. 在同语言字幕窗口中进行词法检索。
4. 将最佳候选和完整结果 JSON 保存到短剧任务项。
5. 任务结束后汇总完成与失败数量。

当前没有把翻译回退接入批量执行器。翻译服务和低结果阈值确定后，再按“原语种优先、低结果后才跨语种翻译”的规则扩展。

## 验证

已通过回归测试：

- 短剧任务归属隔离与原子领取。
- 文本输入解析后执行词法检索。
- 最佳候选的剧 ID、集数和证据时间持久化。
- 语言路由的同语种过滤与手动覆盖。

下一步为前端增加独立的“短剧字幕比对”入口、批量任务列表和任务详情结果视图，再补任务暂停、恢复、删除、导出及专用复核能力。
