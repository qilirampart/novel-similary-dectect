# 短剧字幕复核与证据导出

短剧字幕批量任务已增加独立复核与导出能力，不复用小说结果复核表。

## 复核

每个短剧任务项可保存以下状态：

- `pending`：待复核
- `confirmed_high_risk`：确认高风险
- `needs_followup`：继续跟进
- `false_positive`：标记误报

复核状态、复核人、备注和更新时间存入 `drama_subtitle_task_reviews`。短剧任务详情会带回这些字段，页面可直接切换每条结果的复核状态。

## 导出

新增接口：

```text
GET /api/v1/drama-subtitles/tasks/{task_id}/exports/review-xlsx
```

导出为 Excel，并按“确认高风险”“继续跟进”“标记误报”分工作表。每行保留：

- 任务和输入条目编号
- 来源平台、来源标识、短剧名称、集数、作者
- 输入语言、完整输入台词、检测耗时
- 命中 `book_id`、命中剧名、集数和字幕语言
- 候选字幕证据窗口与起止时间
- 完整命中字幕证据文本
- 复核状态、复核人、复核备注和更新时间

当前导出已经适合作为短剧字幕侵权排查的阶段性复核表。YouTube 视频 ID、字幕轨道类型、YouTube 原始片段时间范围会在下一阶段随 cue 分段输入契约一并加入，避免以不完整的元数据字段做临时兼容。
