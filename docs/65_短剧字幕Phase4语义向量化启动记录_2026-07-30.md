# 短剧字幕匹配 Phase 4：语义向量化启动记录

## 独立语义索引

短剧字幕语义检索使用独立 Qdrant collection：

```text
drama_subtitle_window_embeddings_qwen3_8b_1024_v1
```

向量化对象是 `drama_subtitle_windows` 中的字幕行窗口，不复用小说章节、小说 semantic chunk 或小说 collection。每个点保留 `window_uid`、`book_id`、剧名、集数、字幕行范围、时间范围和文本摘要，完整证据文本仍以 SQLite 为准，因此 Qdrant 只承担向量近邻检索职责。

## 实现内容

- 新增 `service/drama_subtitle_semantic_schema_v1.sql`，记录字幕窗口的向量同步状态。
- 新增 `scripts/embed_drama_subtitle_windows_v1.py`，支持幂等写入、断点续跑、进度 JSON、按剧筛选和 `--force` 重建。
- 新增 `scripts/search_drama_subtitle_semantic_v1.py`，支持查询向量化、Qdrant 检索、按 `book_id + episode_order` 聚合，以及从 SQLite 回填完整复核证据。

Qdrant 点 ID 由 `window_uid` 生成稳定 UUID；即使重跑同步，也会覆盖同一窗口点而不是产生重复向量。

## 全量任务状态

2026-07-30 已使用 64 条批大小启动全量回填。启动时已有 141 条小样本向量，待处理窗口为 309,057 条。任务进度写入：

```text
logs/drama_subtitle_embedding_full_progress.json
```

标准输出和错误日志分别写入：

```text
logs/drama_subtitle_embedding_full_stdout.log
logs/drama_subtitle_embedding_full_stderr.log
```

任务中断后直接再次执行同一命令即可续跑，已同步窗口会由同步状态表自动跳过。
