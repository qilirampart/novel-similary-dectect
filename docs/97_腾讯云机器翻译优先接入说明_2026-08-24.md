# 腾讯云机器翻译优先接入说明

## 当前结论

短剧字幕跨语言回退现已改为腾讯云优先、DeepL 备用。原语言召回和语义召回流程不变，只有原语言没有形成可靠命中时才进入翻译回退，因此翻译服务不会增加正常命中路径的耗时。

腾讯云使用官方 `TextTranslate` 接口，endpoint 为 `https://tmt.tencentcloudapi.com`，通过 TC3-HMAC-SHA256 完成请求签名。已使用当前腾讯云账号在本地真实调用验证中文到英文，项目代码返回正常，单次短文本耗时约 `0.48s`。

## Provider 顺序

默认顺序为：

```text
tencent -> deepl
```

腾讯云调用成功后，结果中的 provider 为 `tencent-tmt-v1`。如果腾讯云出现超时、签名错误、权限错误、额度耗尽或服务端异常，系统会在剩余总预算内切换 DeepL。切换原因写入 `translation_fallback.attempts[].provider_failures`，便于前端和 API 接入方提示“翻译服务发生降级”。

翻译缓存按 provider 隔离，腾讯云和 DeepL 不会互相覆盖缓存。相同用户、相同原文、相同语言方向再次请求时优先读取当前 provider 的缓存。

## 环境变量

本地配置位于被 Git 忽略的 `.env.local.ps1`，云端应写入 `novel-similarity-api.service` 的 systemd 环境变量，不应写入代码仓库或普通文档。

```text
DRAMA_SUBTITLE_TRANSLATION_ENABLED=1
DRAMA_SUBTITLE_TRANSLATION_PROVIDER_ORDER=tencent,deepl
DRAMA_SUBTITLE_TENCENT_SECRET_ID=...
DRAMA_SUBTITLE_TENCENT_SECRET_KEY=...
DRAMA_SUBTITLE_TENCENT_REGION=ap-shanghai
DRAMA_SUBTITLE_TENCENT_PROJECT_ID=0
DRAMA_SUBTITLE_TENCENT_ENDPOINT=https://tmt.tencentcloudapi.com
DRAMA_SUBTITLE_DEEPL_API_KEY=...
DRAMA_SUBTITLE_TRANSLATION_TIMEOUT_SECONDS=12
DRAMA_SUBTITLE_TRANSLATION_TOTAL_TIMEOUT_SECONDS=20
```

也兼容腾讯云常用环境变量名 `TENCENTCLOUD_SECRET_ID`、`TENCENTCLOUD_SECRET_KEY`、`TENCENTCLOUD_REGION` 和 `TENCENTCLOUD_PROJECT_ID`。项目专用变量优先级更高。

## 发布注意事项

云端发布时只需要同步代码和前端/后端构建产物，并在 systemd 环境中配置腾讯云密钥。不要把 SecretKey 放入 release 压缩包、Git、日志或 API 响应。由于当前密钥曾在聊天中展示，正式发布前应重新生成 SecretKey，并在本地和云端同步替换。
