# 短剧页面拆分与召回可解释指标

## 页面调整

短剧字幕功能拆分为单条检测页和独立批量任务页：`/drama-subtitles` 只承担单条输入、候选证据和单条检测结果；`/drama-subtitles/batch` 负责文件上传、任务进度、任务控制、逐条复核和证据导出。两页之间保留明确跳转入口，批量页不再与单条检测争夺页面空间。

## 指标调整

候选结果新增“词法覆盖率”，定义为查询文本唯一三元词中出现在候选证据文本内的比例，同时展示共享三元词数量、查询三元词总数和命中窗口数量。该指标用于解释召回依据，不冒充经过标注集评估得到的真实召回率。共享三元词在证据文本中以高亮标识，便于复核人员判断候选是否因真实重合进入结果。

## 验证

- 后端短剧检索、任务存储和输入解析测试：`13 passed`
- 前端 `npm run build`：通过
- Playwright 浏览器验证：单条页与批量页分离成功；真实英文字幕 Top1 词法覆盖率为 `100.0%`，共享三元词 `283/283`；页面生成 `10` 个候选卡片并显示证据高亮。
