# 云端封面巡检局部代理部署记录

## 部署结论

2026 年 9 月 9 日，云服务器已部署独立的 mihomo-cover.service，仅用于后续封面巡检模块访问 YouTube 页面和缩略图 CDN。代理监听地址为 127.0.0.1:17890，未开放公网端口，也未修改服务器默认路由、系统 DNS、防火墙、Docker 网络或全局代理环境变量。

小说相似度匹配、短剧字幕匹配、Qdrant、Nginx、DramaLoom、社区项目及其他 Docker 服务继续使用原有直连网络。后续封面采集进程需要显式配置 http://127.0.0.1:17890 才会经过代理，未显式配置的服务不会受到影响。

## 隔离与资源限制

代理以独立低权限用户 mihomo-cover 运行，配置和节点快照权限为 600。systemd 限制其最大内存为 256 MiB、CPU 配额为单核的 50%，并启用了 NoNewPrivileges、文件系统保护、内核保护和命名空间限制。服务不启用 TUN、透明代理和外部控制端口。

Mihomo 版本固定为 v1.19.30，安装前校验了官方发布文件的 SHA-256。服务已设为开机启动，代理异常只会影响显式使用该端口的封面采集任务。

## 验证结果

- YouTube 首页返回 HTTP 200，下载约 876 KB，耗时约 1.03 秒。
- YouTube 缩略图 CDN 返回 HTTP 200，类型为 image/jpeg，下载约 19 KB，耗时约 0.44 秒。
- 代理实际内存占用约 25 MiB。
- 端口 17890 只监听 127.0.0.1，防火墙未增加该端口。
- 小说匹配 API 健康检查返回正常，Qdrant、Nginx、Docker、DramaLoom 均保持运行。
- 社区项目当前运行 blue 槽；green 槽在代理部署期间由其自身蓝绿发布流程正常停止，并非代理导致。
- 服务器默认路由、阿里云 DNS 和 Docker 网桥与部署前一致，systemd 未出现全局代理环境变量。

## 订阅现状

用户提供的 Flower_SS 在线转换地址、备用域名和内层原始订阅地址均对自动化请求返回 HTTP 403，因此未能自动取得最新 Flower_SS 配置。本次最终使用本机当前已验证可联网的 Clash 合并配置提取节点，并只保留节点定义，不复制本机规则、DNS、TUN 或全局代理设置。

云服务器对部分节点域名的 DNS 查询会返回 SERVFAIL。为避免修改服务器系统 DNS，部署脚本在本地解析节点地址并写入专属节点快照，同时保留 VLESS/Hysteria2 的 SNI 或 servername。当前节点快照可用，但不支持在线自动更新；节点失效或订阅变化后需要重新生成并部署快照。若必须切换到 Flower_SS，需要从 Clash Verge 导出最新 YAML，再使用同一安装脚本替换节点快照。

## 使用与回滚

封面采集程序只应在 YouTube 页面、缩略图和 yt-dlp 请求上显式指定 http://127.0.0.1:17890。模型 API、数据库、字幕匹配和其他外部接口不应继承该代理。

回滚时只需停止并禁用 mihomo-cover.service，现有业务服务无需重启；封面采集程序应在代理不可用时明确返回网络错误，不得静默改用系统级代理。
