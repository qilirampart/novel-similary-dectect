## 结论与后续

当前本地短剧字幕链路已具备真实英文字幕的稳定批量处理能力：解析正确、词级召回和同语言 4B 语义召回均正常，单条平均约 3.3 秒，准确性仍应以人工复核金标统计。下一步优先补充三项能力：为失败条目增加可控重试和单条重跑；让 API 启动时自动扫描并恢复遗留的 `running` 短剧任务；从真实字幕中建立“正确原著、相近但非目标、无关候选”人工金标，再计算真正的 Top1、Top5、Top10 召回率和误报率。Reranker 暂不接入默认链路，避免在没有真实金标的情况下增加延迟并误判收益。
